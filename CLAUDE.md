# CLAUDE.md

## Projet

Développement d'un jeu de cartes à collectionner (TCG).
La direction du jeu (règles, contenu, fonctionnalités) est donnée par l'utilisateur : ne pas l'inventer sans son accord.

## Règles de base

1. **Périmètre strict** : ne jamais sortir de ce dossier (`TCG One Piece Test`) sans l'accord explicite de l'utilisateur. Cela vaut pour la lecture, l'écriture et les commandes.
2. **Code** : tout le code du jeu se trouve uniquement dans ce dossier.
3. **Choix techniques** : le choix du langage et des outils est laissé à Claude, qui en informe l'utilisateur.
4. **Code sur demande uniquement** : ne coder que ce que l'utilisateur demande ouvertement. Aucune fonctionnalité, aucun fichier de code ni aucun ajout non demandé.
